# AvrorA Tamagotchi

Тамагочи с Авророй (серебряная лисица). Кормишь, гладишь, играешь, укладываешь спать,
танцуешь. Игра собирается в APK через GitHub Actions.

## Что внутри

- `web/` — сама игра: three.js + WebView. Модель `web/model/aurora.glb` получается из
  `models/Silver_Fox_AvrorA_model.glb` при сборке (упрощение до ~100k треугольников, текстуры 1024).
- `web/js/state.js` — правила игры (сытость, настроение, энергия, близость, сон). Без DOM, покрыто тестами.
- `web/main.js` — сцена, жесты, анимация.
- `app/` — Android-обёртка (WebView, модель читается из APK без интернета).
- `.github/workflows/build-apk.yml` — сборка debug APK.

## Управление

- Кнопки внизу: рыба, ягода, пирожное — кормят; играть и танец — поднимают настроение, тратят энергию;
  спать — восстанавливает энергию.
- Провести пальцем по модели — погладить (растёт близость).
- Тап по модели — тык, она реагирует.
- Танец — 12 секунд танцует под 120 BPM, меняется свет.

Состояние сохраняется на устройстве (localStorage). Пока Аврора спит или ты не играешь,
показатели падают, но она не умирает.

## Сборка через GitHub

1. Создай репозиторий и загрузи туда всё содержимое этой папки, включая `models/Silver_Fox_AvrorA_model.glb`
   (файл около 57 МБ, это меньше лимита GitHub в 100 МБ).
2. Открой вкладку **Actions** → **Build APK** → **Run workflow** (или просто пуш в `main`).
3. Когда сборка зелёная, скачай артефакт `aurora-tamagotchi-debug` и установи APK на телефон.
   Разреши установку из неизвестных источников.

## Локальная проверка логики


## Анимации (Mixamo)

Модель сама по себе без скелета. Чтобы ходьба, сидение, игра и умиление выглядели по-настоящему:

1. Открой модель на mixamo.com (нужен бесплатный аккаунт Adobe). Mixamo принимает FBX, поэтому
   сначала конвертируй `web/model/aurora.glb` (появится после `npm run prepare-web`) в FBX в Blender.
2. Авто-риг, затем скачай персонажа (FBX Binary, With Skin) как `models/mixamo/character.fbx`.
3. Для каждой анимации скачай FBX Binary, Without Skin, и положи в `models/mixamo/` под именами из
   `models/mixamo/README.txt`.
4. Запушь. Сборка сама скопирует файлы в `web/anim/` и подключит анимации.

Без этих файлов игра работает как раньше, с процедурными движениями.

## Что можно доработать

- Подпись релиза: сейчас собирается debug-APK. Для постоянного ключа нужен keystore и секреты в GitHub.
- Иконка приложения и название пакета (`com.aurora.tamagotchi`) — меняются в `app/build.gradle.kts` и `AndroidManifest.xml`.
